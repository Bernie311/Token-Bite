# Token Bite

把本机 Codex 的用量、额度和任务状态，放进一个 Windows 浮窗。

本仓库用于产品展示、使用说明、问题反馈和程序下载。**Token Bite 为闭源软件，本仓库不公开应用源代码。**

首次试用版正在准备中，程序下载附件将通过本仓库 Releases 提供。

- 运行环境：Windows 11 x64
- 查看今日及本次任务批次的确认 Token 消耗
- 展示官方剩余额度、可见输出速率和任务状态
- 提供模型、聊天、工具及活动趋势分析

本地统计面向 Codex，不包含普通 ChatGPT 聊天或其他设备的用量。

Token Bite 是独立项目，与 OpenAI、Anthropic 无隶属或背书关系。
