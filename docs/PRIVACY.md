# 隐私说明

适用版本：0.33.3-rc.1。核对日期：2026-10-18。

## 读取的数据

Token Bite 读取本机 Codex 会话日志、会话索引及本地运行状态，用于提取请求用量、时间、模型、聊天标题、来源、工具结果和活动计数。输出速率在内存中处理可见输出文本；识别技能读取时会检查相关命令记录。解析过程会接触日志内容，因此不能理解为“完全不接触聊天记录”。

默认数据位置为当前用户的 `.codex`，并遵从已有 `CODEX_HOME`。程序通过本机 Codex CLI 的既有登录机制请求官方额度，不要求向 Token Bite 粘贴认证令牌；已核对路径未发现直接读取 `auth.json` 的实现。

选择“跟随系统”时，会只读 Windows 当前用户的应用主题设置。启用跟随启动时，会检查目标应用的进程路径和桌面窗口是否存在，不以窗口正文作为启动条件。

## 本地保存

程序同级 `data` 保存窗口设置、跟随启动偏好、SQLite 用量账本、诊断状态及必要备份。账本包含请求计数、时间、会话／轮次标识和来源路径。异常设置恢复可能生成原设置备份。

已检查的保存和导出路径不以保存聊天正文、完整命令、入参、工具输出或原始错误文本为目的。`data`、诊断信息及 CSV 仍可能包含聊天标题、路径或标识，应按私人材料处理。

CSV 保存在用户选择的位置。退出后可自行备份或删除 `data`；删除会失去设置和本地缓存，不能保证重新发现全部旧记录。

## 联网与系统设置

官方额度通过本机 Codex CLI 查询，CLI 可能连接 OpenAI 服务。本地统计读取日志，运行状态使用本机通信；分词词表随包提供，无需在线下载。

在已核对的应用源码中，未发现独立的遥测、广告或自动上传账本入口。这不构成全部依赖的网络审计，也不承诺绝不联网。

自动启动为可选功能。启用时会配置当前用户 Windows Run 启动项 `TokenMiniAutoLaunch` 并保存偏好；关闭该功能会撤销相应启动设置。

## 反馈与演示

公开动图使用隔离演示数据；数字、额度、标题和活动不是实际账户记录。它们不是性能测试或异常恢复验收的替代品。

公开问题请使用本仓库 Issues，避免附原始 `data`、聊天日志、密钥或认证文件。涉及隐私或素材权利的问题，可通过作者公开的 [X 账号 @JotaroKujoX](https://x.com/JotaroKujoX) 联系；请先沟通，不要直接发送秘密信息。
